Drone Vision
============

Описание
--------

Приложение на python3 для работы с распознаванием объектов камерой дронов Океаника (Кит и другие).

Реализовано универсальное приложение на python 3.11, подключающееся к ROS (https://wiki.ros.org/noetic) по tcp протоколу
(через WiFi сеть на буе или локально внутри самого дрона).

Подключение идет к порту 9090 сервиса ROSBridge (https://wiki.ros.org/rosbridge_suite) при помощи библиотеки roslibpy
(https://roslibpy.readthedocs.io/en/latest/) с использованием websocket транспорта, что также совместимо с веб браузером.
Сервис ROSBrigde входит в текущую прошивку дронов Океаника.

Зависимости
-----------

Разработка и отладка: Linux, Docker.
Подключение к WiFi сети дронов Океаника для получения видеокадров с камеры Raspberry Pi.

Разработка
----------

Модели TFLite располагаются в директории `models`. Поддерживаются актуальные версии TensorFlow API (2.19+)
Код приложения расположен в директории `scripts/main.py`.
Зависимости (необходимые модули python) перечислены в `requirements.txt`

Также в scripts расположены вспомогательные скрипты для тестирования модели на PC:

- `test_model.py` - код для получения статистики по модели и запуска пробного инференса.
- `test_camera.py` - код для тестирования модели распознавания цифр на кадрах с видеоустройства V4L (`/dev/video0`).

Скрипты сборки и запуска:

- `build.sh` собирает docker контейнеры (под aarch64 и amd64 архитектуры)
  с зависимостями приложения и экспортирует их в директорию `build`. Описание образа docker контейнера размещено в `Dockerfile`.
- `debug.sh` запускает собранный docker контейнер с приложением на PC, при этом код приложения и модели монтируются с хостовой системы,
  что позволяет вносить модификации в код прямо в директории scripts, не пересобирая контейнер заново.
- `debug_pi.sh` запускает собранный docker контейнер с приложением на Raspberry Pi, при этом код приложения и модели монтируются с файловой системы дрона,
  например из `/home/pi/drone_vision`, что также упрощает отладку взаимодействия с дроном.
- `deploy.sh` загружает собранный docker контейнер из файла на Raspberry Pi (необходимо скопировать из `build` tar.gz файл для aarch64 в `/home/pi/drone_vision`)
  и стартует его так, чтобы он продолжил работу даже после перезапуска ОС дрона.
- `run.sh` разово запускает приложение в собранном docker контейнере.
