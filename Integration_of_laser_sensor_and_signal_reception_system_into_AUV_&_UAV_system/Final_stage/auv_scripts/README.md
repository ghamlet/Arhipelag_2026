# AUV Scripts - Скрипты управления подводным дроном

Структура папок и описание всех скриптов для тестирования и управления АП "Океаника КИТ".

---

## 📁 Структура

```
auv_scripts/
├── library.py                    # Библиотека DroneLibrary (оригинал)
├── telemetry/                    # 📊 Чтение телеметрии (только чтение)
├── set_parameters/               # ⚙️ Установка параметров + удержание
└── stabilization/                # 🎯 Стабилизация положения
```

---

## 📊 telemetry/ — Чтение телеметрии

Скрипты только читают данные с датчиков, **не управляют** дроном (`takecontrol=False`).

| Скрипт | Описание | Заметки |
|--------|----------|---------|
| `get_course.py` | Выводит текущий курс (рыскание) в градусах каждые 0.5с | |
| `get_pitch.py` | Выводит текущий тангаж (наклон вперед/назад) в градусах | |
| `get_roll.py` | Выводит текущий крен (наклон влево/вправо) в градусах | |
| `get_depth.py` | Выводит текущую глубину в метрах | |

**Общие параметры:** `READ_INTERVAL=0.5`, `DURATION=30` (0 = бесконечно)

---

## ⚙️ set_parameters/ — Установка параметров

Скрипты устанавливают заданное значение и удерживают его N секунд (`takecontrol=True`).

| Скрипт | Описание | Параметры по умолчанию | Заметки |
|--------|----------|------------------------|---------|
| `set_course.py` | Устанавливает курс (рыскание) | `TARGET_COURSE=90°`, `HOLD_TIME=15с` | |
| `set_pitch.py` | Устанавливает тангаж | `TARGET_PITCH=15°`, `HOLD_TIME=15с` | + = вперед, - = назад |
| `set_roll.py` | Устанавливает крен | `TARGET_ROLL=10°`, `HOLD_TIME=15с` | + = вправо, - = влево |
| `set_depth.py` | Устанавливает глубину | `TARGET_DEPTH=5.0м`, `HOLD_TIME=20с` | |
| `set_speed_move.py` | Устанавливает скорость 80% и плывет | `TARGET_SPEED=80%`, `MOVE_TIME=20с` | Отрицательная скорость = назад |

---

## 🎯 stabilization/ — Стабилизация положения

Скрипты с **автоматической коррекцией** — слеят за отклонением и возвращают к целевому значению.

| Скрипт | Описание | Параметры по умолчанию | Заметки |
|--------|----------|------------------------|---------|
| `level_horizon.py` | Выравнивает дрон по горизонту (тангаж=0, крен=0) | `STABILIZE_TIME=60с`, `TOLERANCE=1.0°`, интервал коррекции 2с | |
| `hold_depth.py` | Удерживает заданную глубину с коррекцией | `TARGET_DEPTH=10.0м`, `HOLD_TIME=60с`, `TOLERANCE=0.3м` | |
| `hold_course.py` | Удерживает заданный курс (простая версия) | `TARGET_COURSE=45°`, `HOLD_TIME=60с`, `TOLERANCE=5.0°` | |
| `course_hold.py` | Удерживает курс с автокоррекцией и статистикой | `TARGET_COURSE=45°`, `HOLD_TIME=60с`, `TOLERANCE=5.0°` | Показывает макс. отклонение и кол-во коррекций |
| `full_stabilization.py` | **Полная стабилизация**: глубина + тангаж + крен + курс одновременно | Все параметры в начале файла, `HOLD_TIME=60с` | Итоговая статистика по всем осям |

## 🚀 Быстрый старт

```bash
# Переход в папку скриптов
cd /home/arrma/PROGRAMMS/Arhipelag_2026/Integration_of_laser_sensor_and_signal_reception_system_into_AUV_&_UAV_system/Final_stage/auv_scripts

# 1. Проверка телеметрии (дрон НЕ управляется)
python3 telemetry/get_depth.py

# 2. Установка глубины
python3 set_parameters/set_depth.py

# 3. Стабилизация по горизонту
python3 stabilization/level_horizon.py

# 4. Полная стабилизация (все параметры)
python3 stabilization/full_stabilization.py
```

---

## ⚠️ Важно

- Все скрипты вызывают `drone.stop()` в блоке `finally` — моторы выключаются при завершении или `Ctrl+C`
- Для работы нужен запущенный ROS и доступные action-серверы дрона
- Параметры настраиваются в начале каждого файла (константы)
- `takecontrol=True` — автономный режим, `False` — только чтение/пассивный мониторинг
