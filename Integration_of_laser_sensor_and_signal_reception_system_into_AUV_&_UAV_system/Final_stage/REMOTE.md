Монтирование через SSHFS (SSH Filesystem) позволяет подключить удаленную папку с Raspberry Pi так, будто это обычная флешка или жесткий диск, вставленный в ваш компьютер.
------------------------------
## Как это будет выглядеть?

   1. В файловом менеджере: В вашей системе (проводнике Ubuntu/Linux) появится новый «диск» или папка с сетевым значком. Вы сможете заходить туда, кликать по файлам мышкой, копировать их ctrl+c / ctrl+v.
   2. В редакторе кода: Вы сможете открыть эту примонтированную папку в любом локальном редакторе (VS Code, PyCharm, Sublime Text). Когда вы нажимаете Ctrl + S, файл автоматически и мгновенно сохраняется прямо на Raspberry Pi.

------------------------------
## Как это реализовать (Инструкция для Linux / Ubuntu)
Поскольку в вашем прошлом запросе фигурировал путь /home/arrma/, вы, скорее всего, работаете на Linux (Ubuntu). Вот пошаговый процесс:
## Шаг 1. Установите SSHFS на ваш локальный ПК
Откройте терминал на своем компьютере (не на Pi!) и выполните:

sudo apt update
sudo apt install sshfs

## Шаг 2. Создайте пустую папку для монтирования
Это место (точка монтирования), куда «отобразится» содержимое с Raspberry Pi. Например, создадим папку drone_pi в вашем домашнем каталоге:

mkdir -p ~/drone_pi

## Шаг 3. Примонтируйте удаленную папку
Выполните команду монтирования. Мы используем ваши данные из прошлого запроса:

sshfs pi@192.168.88.155:/usr/local/drone_ros/src/drone/scripts/examples ~/drone_pi -o allow_other

Если у пользователя pi нестандартный порт SSH, добавьте в конец -p ПОРТ.
Система попросит ввести пароль от пользователя pi.
Готово! Теперь откройте папку ~/drone_pi на своем компьютере — там лежат все скрипты ROS с дрона.
------------------------------
## Как это отключить (размонтировать)?
Когда вы закончите работу, удаленный диск нужно правильно отключить:

fusermount -u ~/drone_pi

## Важные нюансы

* Зависимость от Wi-Fi: Если связь с Raspberry Pi оборвется, примонтированная папка «зависнет» в проводнике, пока сеть не восстановится или пока вы её не размонтируете.
* Скорость: Открытие тяжелых файлов (или поиск по коду) может работать чуть медленнее, чем на ПК, так как данные каждый раз читаются по сети. Для ROS-скриптов (Python/C++) скорости Wi-Fi хватает с запасом.

Если у вас возникла какая-то ошибка при монтировании или вы хотите настроить автоматическое подключение при старте системы, дайте знать — мы это настроим!
