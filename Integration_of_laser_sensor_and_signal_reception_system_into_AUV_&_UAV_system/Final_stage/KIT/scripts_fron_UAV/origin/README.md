# Инструкция по управлению подводным роботом «Океаника КИТ» с помощью библиотеки DroneLibrary

## Подключение и инициализация

1. Создайте объект дрона
```python
drone = DroneLibrary()
```

2. Запустите систему управления
```python
drone.start(takecontrol=True) # True - автономное управление, False – ручное
```

## Основные команды управления

### Управление глубиной

1. Установить глубину (абсолютное значение)
```python
drone.set_depth(5) # Погружение на 5 метров
```

2. Изменить глубину (относительное изменение)
```python
drone.change_depth(2) # Увеличить глубину на 2 метра
```

### Управление ориентацией

1. Курс (рыскание)
```python
drone.set_course(45) # Установить курс 45°   КАК это работает 
drone.change_course(10) # Повернуть на 10° вправо
```

2. Тангаж (наклон вперед/назад)
```python
drone.set_pitch(15) # Наклон вперед на 15°   С удержанием? и как установить горизонтальный уровень
drone.change_pitch(-5) # Уменьшить наклон на 5°
```

3. Крен (наклон вбок)     КАК установить прямо
```python
drone.set_roll(10) # Наклон вправо на 10°
drone.change_roll(-3) # Уменьшить крен на 3°
```

### Управление скоростью

1. Изменить скорость (абсолютное значение)
```python
drone.set_speed(80) # Установить скорость 80%
```

1. Изменить скорость (относительное изменение)
```python
drone.change_speed(-10) # Уменьшить скорость на 10%
```

### Дополнительные функции

1. Фонари
```python
drone.set_headlight(75) # Яркость 75%
```

2. Манипулятор
```python
drone.set_hand(1) # Активировать манипулятор
```

3. Полезная нагрузка
```python
drone.set_payload(0) # Отключить нагрузку
```

### Получение текущих данных

```python
current_depth = drone.get_depth() # Текущая глубина
current_course = drone.get_course() # Текущий курс
current_pitch = drone.get_pitch() # Текущий тангаж
current_roll = drone.get_roll() # Текущий крен
```

### Безопасное завершение

```python
drone.stop() # Корректное отключение управления
```

### Полезные советы

1. Все значения углов указываются в градусах
2. Скорость задается в процентах (-100% до 100%)
3. Для плавного управления используйте функции change_

### Пример программы

```python
drone = DroneLibrary()
drone.start()
drone.set_depth(3)
drone.set_course(90)
drone.set_speed(50)
drone.set_headlight(100)
time.sleep(10) # Выполнять маневр 10 секунд
drone.stop()
```

Для дополнительной информации смотрите документацию к методам класса DroneLibrary.

## Примеры управления дроном

Примеры располагаются в прошивке в `/usr/local/drone_ros/src/drone/scripts/examples`

### circle.py

Заставит дрон выполнить маневр кругового движения.
Переменная speed задает радиус поворота.

### forward.py

Заставит дрон выполнить серию движений вперед-назад на фиксированной текущей глубине.
Переменная speed задает скорость прямолинейного движения.

### headlight.py

Заставит дрон включить на полную мощность фонари, и через 5 секунд их выключить.

### kiter.py

Пример сложного движения дрона.

### laser.py

Заставит дрон включать и выключать лазер, передавая морзянкой букву А.

### points.py

Заставит дрон пройти по сложной траектории, указанной в массиве waypoints в формате (глубина, скорость),
после каждого отрезка меняя курс на 90 градусов.

### rotation.py

Заставит дрон развернуться на месте, не меняя глубины.

### search.py

Имитация процесса распознавания объектов на дне.

### square.py

Заставит дрон выполнить серию прямолинейных движений по сторонам квадрата в подводном положении на фиксированной глубине.
Переменная speed задает скорость движения, time_to_move - время движения по каждой из сторон.

### stop.py

Заставит дрон остановиться и перейти в режим ручного управления.
