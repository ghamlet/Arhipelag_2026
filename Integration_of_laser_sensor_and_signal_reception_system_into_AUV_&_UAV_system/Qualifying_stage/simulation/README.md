# Инструкция по запуску

## autonomous_behavior.py

Скрипт автономного поведения дрона: пролёт по территории, поиск ArUco-маркера, определение его координат и возврат домой.

### Зависимости

```bash
pip install pioneer-sdk opencv-python numpy
```


### Запуск

```bash
python3 autonomous_behavior.py
```


## Алгоритм работы

### Цикл 1 — поиск маркера

Дрон пролетает по 6 точкам маршрута:

```
(-3, 3.5) → (-3, -3.5) → (0, -3.5) → (0, 3.5) → (3, 3.5) → (3, -3.5)
```

На каждом кадре камеры проверяет есть ли ArUco-маркер. Если маркер обнаружен 5 раз подряд — он считается подтверждённым (не фантом).

Если прошли все точки и не нашли маркер — дрон садится.

### Цикл 2 — сбор координат

После нахождения маркера дрон зависает на 2 секунды. В течение этого времени с каждого кадра собираются:

- **Глобальные координаты** маркера (где он лежит на карте)
- **Координаты относительно дрона** (система координат дрона: X — вправо, Y — вперёд, Z — вверх)

Измерения усредняются для точности.

### Позиционирование

Дрон летит точно в глобальные координаты маркера на высоте полёта (2 м). Зависает над ним на 5 секунд.

### Возврат домой

Дрон возвращается в точку взлёта и садится.

---

## Что выводится в консоль

```
Положение маркера относительно собственной системы координат дрона
x=-1.14m y=0.45m z=-2.0m
ID маркера 2
```

- **x** — смещение вправо/влево (отрицательный = влево от носа)
- **y** — смещение вперёд/назад (положительный = впереди)
- **z** — расстояние до земли (отрицательный = ниже дрона)
