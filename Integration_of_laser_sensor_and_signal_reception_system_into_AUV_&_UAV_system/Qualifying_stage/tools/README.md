# Tools

Скрипты для генерации датасета и тестирования фильтров.

## Скрипты

### `create_cube_texture.py`

Интерактивный 3D-рендерер куба через OpenCV. Используется для создания текстур кубов, которые потом компонируются на фон.

**Запуск:**
```bash
python tools/create_cube_texture.py
```

**Управление:**
- Мышь — вращение куба
- `S` — сохранить скриншот в `dataset/cubes/`
- `ESC` / `Q` — выход

---

### `generate_dataset.py`

Генератор изображений датасета. Накладывает изображения кубов на фон и применяет случайные подводные искажения: освещение, мутность, блики, частицы, цветовые фильтры.

**Запуск:**
```bash
python tools/generate_dataset.py
```

Генерирует `NUM_IMAGES` изображений в `dataset/black_box/`.

Также предоставляет функции `apply_*` для использования другими скриптами.

---

### `filter_lab.py`

Веб-интерфейс для интерактивного тестирования фильтров. Загружаете фото — видите оригинал слева и результат справа в реальном времени.

**Запуск:**
```bash
python tools/filter_lab.py
```

Откройте http://localhost:5000 в браузере.

**Возможности:**
- Загрузка любого изображения
- Сплит-вью: оригинал / результат
- Слайдеры для настройки параметров каждого фильтра
- Включение/отключение фильтров чекбоксами
